# fusionpbx-app-notes
The notes can be used to save information on any topic with text and markdown format.

## Install
```
cd /var/www/fusionpbx/app
git clone https://github.com/fusionpbx/fusionpbx-app-notes.git notes
chown -R www-data:www-data /var/www/fusionpbx
php /var/www/fusionpbx/core/upgrade/upgrade.php
```
